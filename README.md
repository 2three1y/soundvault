# Soundvault

An accessible, searchable, lightweight catalog of soundpack and audio resources from [MG Storage](https://files.mad-gamer.com/).

Open `index.html` directly or enable GitHub Pages to publish it. The catalog links to source-hosted material; no audio binaries are mirrored in this initial commit. Large bundles remain at the original host. Availability, permissions, and licensing should be checked with the source.

The catalog includes FastSM Soundpacks, Audio (including iOS/macOS/VoiceOver discovery), NVDA, Sound Manager Schemes, Soundfonts, Ubuntu Sounds, TTCom Sounds and Texts, NVGT Scripts, and Miscellaneous resources.
